# 吃什么转盘 🍜

一个帮助选择困难症用户决定今日菜单的工具，通过趣味转盘形式随机抽取家常菜。

## 功能特点

- 🎡 **随机转盘** - 点击按钮转动转盘，随机选择菜品
- 🏷️ **分类筛选** - 支持全部/荤菜/素菜分类筛选
- ⭐ **收藏功能** - 收藏喜欢的菜品，方便下次快速找到
- 📜 **历史记录** - 自动记录最近抽取的 20 道菜
- 🔄 **跳过重抽** - 不满意可以继续转动，直到选到满意的
- 📱 **移动端适配** - 专门为手机优化的界面设计

## 使用方法

### 方式一：直接打开

双击 `index.html` 文件，在浏览器中打开即可使用。

### 方式二：本地服务器

```bash
# 使用 Python
python -m http.server 8000

# 或使用 Node.js
npx serve .
```

然后在浏览器中访问 `http://localhost:8000`

### 方式三：部署到服务器

将 `index.html` 上传到任何静态文件服务器即可。

## 数据说明

应用内置了 100 道家常菜的数据：
- **荤菜**：60 道（含肉类、海鲜等）
- **素菜**：40 道（纯素菜品）

每道菜包含：
- 菜品名称和图标
- 所需食材清单（含数量）
- 详细的烹饪步骤

## 数据存储

- 收藏列表和历史记录保存在浏览器 LocalStorage 中
- 刷新页面或关闭浏览器后数据会保留
- 清除浏览器缓存会丢失这些数据

## 技术栈

- React 18（CDN 引入）
- Tailwind CSS（CDN 引入）
- 纯前端实现，无需后端

- ✅ 微信内置浏览器
- ✅ 其他现代浏览器

## 自定义扩展

如需添加更多菜品，编辑 `DISHES_DATA` 数组，添加以下格式的数据：

```javascript
{
  id: 101,
  name: "新菜品名称",
  category: "meat", // 或 "vegetable"
  emoji: "🍳",
  ingredients: ["食材1", "食材2", ...],
  steps: ["步骤1", "步骤2", ...]
}
```
